What an upload does
  • Only the Quantity column is read. Description, Unit and Category come from the catalogue, not from your file.
  • A row you leave out is left alone.
  • Uploading never deletes anything. Deleting rows in the spreadsheet has no effect — remove items on the BOQ screen instead.
  • A blank quantity leaves the existing value alone. Enter 0 to set zero.
  • An item code that is not in the OPEX catalogue rejects the whole file.
