A design user who can open EVERY site in the group (Zuber Q-B); the view refuses anyone else. That is why each site links to its own BOQ unconditionally: the gate that let the user in is the same BOQ read gate the link's target applies. THE PICKER (Alpine). `picker_rows` is every OPEX site with a design assignment that this user can open — one server-rendered list, filtered in the browser. The add POST re-checks everything server-side and refuses the whole request if any site fails, so nothing here is trusted.
