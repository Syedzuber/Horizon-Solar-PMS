{% comment %} Attempt history for one site — every attempt, why it opened, how it ended. THE TWO REWORK LOOPS ARE DELIBERATELY DIFFERENT COLOURS. `qc_failed` is red because the package was wrong; `pm_change_request` is amber because the brief changed. They are the same event shape and different causes, and a screen that renders them identically throws away the only signal that tells a design-quality problem from a requirements problem. Note the PM-change-request rows show "not judged" rather than a verdict: that attempt was closed without QC ever ruling on it, and its qc_verdict stays 'pending' forever by design. Rendering that as "pending" alone would read like a review still in progress. Shared by qc_review.html, change_request.html and site_workspace.html, so the designer, the Head and the PM all read the same history in the same shape. {% endcomment %}
