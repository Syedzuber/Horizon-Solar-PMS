Overdue counts tasks whose due date has passed and which are not completed. An overdue task is also counted under Not Started, In Progress or Blocked, so Overdue is not a separate column total and the row will not sum to Tasks Assigned.

Task counts cover projects that use the task template. RESCO and CAPEX design work is tracked separately and does not appear in these columns.

Done Today counts the user's own tasks that they finished themselves that day: marked Done by them or, on RESCO sites, submitted by them and approved by a reviewer. "+N by others" are the user's tasks that someone else marked Done. "Closed N tasks for others" counts tasks this user finished on someone else's behalf, or that were assigned to nobody, and appears only when there are any. The portal has recorded who completes each task only since 7 Sep 2026, so for earlier dates every completion counts as the assignee's own.

Users are listed by the work they did that day, most first: their own tasks done plus tasks they closed for others.

Projects Assigned counts every project that is still Active. The system has no project-closure step yet, so completed projects remain counted.

Active Today means the user logged in, or performed at least one recorded action (creating, updating, approving, uploading) on the portal that day. Viewing pages is not recorded, so a user who only read the portal shows as not active.
