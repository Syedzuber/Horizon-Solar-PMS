Inputs are named line--; each row's hidden line--id is the line's pk on a resubmit (empty for a new line), which is how the chokepoint edits a line in place. "+ Add line" clones the first row with the next unused index, so indices may have gaps after a removal; the server reads them in order. The last row is cleared, never removed. The quantity box is type="number" step="any" as drawn; the script sets step="1" min="1" when the row's unit counts whole things and step="any" min="0.01" when it measures. A typing aid only: approvals._clean_lines refuses a quantity its unit does not allow.
