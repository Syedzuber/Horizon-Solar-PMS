Reuses Django's existing messages framework: any messages.success/.error/.warning set in the view is rendered here and swapped into #hxMessages (in base.html) out-of-band, so the "N task(s) recalculated" / error / feedback text appears inline without a full-page reload. Iterating {% for message %} consumes the messages, exactly as the base-template block would on a full render. {% endcomment %}
