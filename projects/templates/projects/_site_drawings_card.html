{% comment %} DR-2 — the site drawings card: the released design's drawing PDFs and its BOQ quantities, for the people building an OPEX site. Read-only for every viewer of the site. Context is `site_drawings`, built by site_drawings_views.site_drawings_context(); not drawn at all on Residential / CAPEX (state not_opex, DR-6). Each drawing links to site_drawing_open, which signs the link at the click — nothing is signed on this page. The BOQ is the six allowlisted columns (DR-3) and nothing else: no price, no ordered quantity, no vendor. Make is drawn only when some row has a brand label (show_make), because no OPEX screen can set one yet. The table scrolls inside its own container so the page never scrolls sideways at phone width. CLOSED BY DEFAULT (DR-2c-1) — a deliberate exception to "overview blocks open by default", using the Gantt card's mechanism: Bootstrap collapse without `show`, and aria-expanded "false" on the .block-toggle button, which must stay in step or the chevron points the wrong way on load. So everything a site needs to know without opening it lives in the HEADER (DR-2c-2): the red under-revision and yellow change-requested banners, and a short summary. Only a released site has anything behind the toggle; the other two states are the header alone. THE BOQ BOX (DR-2c-3): above BOQ_SCROLL_ROWS lines (boq_scrolls) the table scrolls vertically inside the same box that already scrolls sideways, about eleven single-line rows tall, with the header row sticky. At or below it there is no inner vertical scroll. {% endcomment %} {% if site_drawings and site_drawings.state != 'not_opex' %}
